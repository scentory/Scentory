SCENTORY v3063 — DEDICATED PERFUME PAGES

Clicking a perfume photo, View perfume, Hot Arrival or Best Seller now opens that perfume's own page and shareable URL.
Product pages include the existing poster, one profile per perfume, all listed sizes and availability, quantity selection, Add to Cart, Share and Back to Shop.
The shop shows starting prices; sizes are chosen on the product page.
Cart contents use the existing shared browser cart. View cart & checkout returns to the existing customer form and Messenger/WhatsApp ordering flow.
Prices, stock, catalogue order, profiles, discovery tools and delivery charges are preserved from v3062.
This update does not add a server, automatic payment processing, an order database or an admin dashboard.
